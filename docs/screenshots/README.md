# Скриншоты для README

[← README проекта](../../README.md)

Галерея снята с настоящего интерфейса приложения. Все названия и суммы вымышлены: **6 источников, 107 записей за январь 2025 — август 2026**. Есть нулевые доходы, пропуски и неактивный источник. Дата браузера зафиксирована на 3 сентября 2026, чтобы медиана и выбранный год не менялись между запусками.

## Переснять

Нужны Node.js 20+ и Playwright. В рабочей копии владельца Playwright уже доступен в `.local/node_modules/`.

Для новой копии, из корня репозитория:

```sh
npm install --no-save --package-lock=false --prefix .local playwright
```

По умолчанию сценарий использует установленный Microsoft Edge:

```sh
node scripts/capture-readme.mjs
```

Если Edge отсутствует, установите Chromium для Playwright:

```sh
node .local/node_modules/playwright/cli.js install chromium
```

Затем в PowerShell:

```powershell
$env:SCREENSHOT_BROWSER = 'chromium'
node scripts/capture-readme.mjs
```

В macOS / Linux:

```sh
SCREENSHOT_BROWSER=chromium node scripts/capture-readme.mjs
```

Зависимости нужны только для съёмки; само приложение обходится без них. Повторный запуск перезапишет девять PNG и `manifest.json` в этой папке.

## Как работает съёмка

Сценарий запускает временный HTTP-сервер на `127.0.0.1` и отдельный браузерный контекст для каждого набора кадров. Он проходит вход с демонстрационным паролем, а все запросы API перехватывает и передаёт существующему тестовому серверу в памяти. Запросы к другим внешним адресам блокируются. Рабочий Google Apps Script и Google Таблица не используются.

Исходные данные находятся в [demo-data.mjs](demo-data.mjs), шаги съёмки — в [capture-readme.mjs](../../scripts/capture-readme.mjs). Интерфейс приложения не подменяется. Анимации отключаются через настройку уменьшения движения, фокус ввода снимается перед кадром, плотность изображения — 2×. Проверяются сумма доходов, число карточек, отсутствие горизонтального переполнения страницы, ошибок браузера и неожиданных сетевых запросов.
