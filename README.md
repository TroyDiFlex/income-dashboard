## Что умеет Поток

| | |
| :--- | :--- |
| **Вся динамика** | Линия, столбцы или плавный график. Всё время, отдельный год или свой период. |
| **Нужные источники** | Выбор нескольких источников и сравнение их доходов на одном графике. |
| **Понятные показатели** | Общая сумма, средний и медианный доход, лучший месяц и самый прибыльный источник. |
| **Структура дохода** | Доли источников и сравнение по общей сумме или среднему за месяц. |
| **Удобный ввод** | Годовая таблица, форма на месяц и быстрое добавление дохода. |
| **Свои настройки** | Названия, цвета и статусы источников, четыре темы, установка как приложения. |

## Как считаются данные

- **Пропуск ≠ ноль.** Пустое поле означает отсутствие записи, `0` — месяц без дохода. Пустое поле при редактировании удаляет запись.
- **Одна сумма на источник за месяц.** Повторное сохранение заменяет эту сумму.
- **Среднее** учитывает месяцы с записями. При сравнении источников для каждого используются его месяцы с записями.
- **Медиана** считается за шесть полных месяцев перед текущим; выбранный период её не меняет, фильтр источников — меняет.
- **Неактивные источники** остаются в истории и расчётах. Удалённые попадают в корзину на 30 дней и до восстановления исключаются из аналитики.
