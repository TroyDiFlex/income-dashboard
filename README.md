# Поток

Личный дашборд доходов на HTML, CSS и JavaScript. Без npm-зависимостей, сборщика и серверного Node.js.

[Открыть дашборд](https://troydiflex.github.io/income-dashboard/)

Можно установить как приложение с отдельной иконкой: ссылка «Установить приложение» доступна справа внизу дашборда после входа. На iPhone откройте сайт в Safari → «Поделиться» → «На экран Домой». Приложению нужен интернет; офлайн-кэширование не используется.

Настройки источника открываются нажатием на название в таблице и в режиме «По месяцу». Удаление из настроек перемещает источник со всеми доходами в корзину на 30 дней. До восстановления они исключены из всех расчётов. Окончательное удаление требует отдельного подтверждения с задержкой 3 секунды.

Корзина хранит время удаления в закрытых свойствах серверного проекта; перемещение и восстановление не меняют ячейки Google Таблицы. Очистка удаляет только строки просроченных источников и их доходов, сохраняя остальные ячейки и оформление. Срок — 30 × 24 часа по серверному времени. Фоновая очистка запускается каждый час; чтение и сохранение также проверяют срок, поэтому просроченный источник восстановить нельзя даже при задержке фонового запуска.

После первого обновления серверу требуется разрешение `script.scriptapp` для фонового запуска. Авторизованный запрос `trashMaintenance` устанавливает один часовой триггер `purgeExpiredSources` и выполняет проверку срока. Перемещение в корзину также проверяет наличие триггера и не меняет данные при ошибке его установки. Сервер обновляется через `.local/clasp.ps1 push` и `update-deployment` существующего веб-приложения.

Проверки: `node --test tests/*.test.mjs`. Тесты корзины используют вымышленные данные и управляемые часы: граница 30 дней, восстановление, повторное удаление, конфликты, отсутствие доступа и сбои записи. Резервные копии и локальные проверки не публикуются и хранятся в исключённой из Git папке `.local/`.
